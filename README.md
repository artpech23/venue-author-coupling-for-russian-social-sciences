# venue-author-coupling-for-russian-social-sciences

В работе предпринимается попытка использовать venue-author coupling, - относительно редкую технику построения карт науки, в которой связи/близости между авторами зависят от схожести их журнальных профилей (т.е. журналов, где они публиковались), - для представления пространства российских социальных наук (с отсечением менее продуктивных и цитируемых авторов) и социологии (без отсечений). В основе всего лежат данные из системы РИНЦ о том, где публиковались российские авторы. 

Финальные карты представлены в сервисе cosmograph, на [социальных ученых](https://run.cosmograph.app/public/83af6d97-01e5-4ca1-904e-e6f6c700f0d4) и [социологов](https://run.cosmograph.app/public/4eab8b87-2e88-4b56-94f1-9bd95f1c1e1f) можно смотреть отдельно.

Репозиторий содержит:
  1. сырые данные, перечисляющие списки авторов и журналов, где (и сколько раз) они публиковались
  2. данные с координатами для "социальных ученых" и социологов в пространствах сниженной размерности (tf-idf --> svd --> umap)
  3. карты в формате html, на тот случай, если cosmograph обвалится
